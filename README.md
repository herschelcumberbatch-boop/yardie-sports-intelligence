# Yardie Sports Intelligence

Yardie is a personal, noncommercial, self-hosted sports analytics assistant running on a private Linux server.

The project integrates authorized, read-only fantasy sports data with independent statistical projections to provide:

- Yahoo Fantasy Basketball lineup recommendations
- Player injury and availability analysis
- Waiver-wire and trade evaluations
- Weekly matchup projections
- NFL Pick'em research and predictions, where supported

**Intended audience:** One individual, for personal use.

**Data access:** Read-only OAuth authorization. No automated roster changes, transactions or pick submissions.

**Distribution:** Private application, not publicly distributed.

This repository provides project information only. Application code, credentials and personal account data remain private.
